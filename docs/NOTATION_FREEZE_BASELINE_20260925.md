## 已接受的产品行为

1. 纯音频保持波形；同一音符 clip 可切换钢琴卷帘、五线谱、简谱，三者共享 MIDI 数据。
2. 卷帘显示钢琴键盘；谱面可选择音符、上下拖动改音高并试听，支持撤销和重做。
3. 谱面编辑保留未修改区域，避免整页闪烁；长谱按可见页加载。
4. 同一小节范围的声部整组分页并标出同时演奏关系；网页可增高，A4 超高声部组明确标记续页。
5. 谱面大小可在 50%–150% 之间选择并在本机记住；缩放不改变音符数据，缩放后拖拽与定位仍准确。
6. 谱面支持点击空白定位、拖动绿线顶端调整进度；播放按钮切换播放/暂停，暂停保留位置，停止归零。
7. 支持五线谱/简谱导出与 PDF 预览；纸张布局与网页缩放独立。
8. 国内 Cloud 外层同步面板可折叠，保留编曲器实例并释放高度。
